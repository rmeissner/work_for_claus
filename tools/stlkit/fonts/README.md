# Outline Sans Bold

The JSON stores printable ASCII and ä outlines and advance widths extracted from Liberation Sans Bold (Liberation Fonts 2.1.5), licensed under SIL OFL 1.1. The renamed outline dataset retains the source copyright and license in LICENSE.txt. Source: https://github.com/liberationfonts/liberation-fonts.

Contours are in original font units. Quadratic/cubic curves were flattened into 12 equal parameter steps per segment using fontTools 4.68.0 BasePen; coordinates were rounded to 0.001 font units. Keeping the contours in the toolkit makes STL generation independent of system fonts and additional Python packages. text_shape scales the finished outline to millimeters.
